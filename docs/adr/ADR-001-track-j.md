# ADR-001: Track J (Next.js + Node + MongoDB), Path J1
Status: accepted. Supersedes the earlier Track P (Django/PostgreSQL) design draft.
Why: team skill is JavaScript/React; Path J1 is the Track J path fully covered by INT252 + INT257 + CSE326; one language end to end; Vercel hosting.
Consequences: MongoDB time-series collection for attendance; BullMQ instead of Celery; money stored as integer paise; Zod instead of DRF serializers.
Action: update the week-2 design document so its stack sections match this ADR.
